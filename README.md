# StudyFlow 🎯

**受験・資格試験・日々の学習をすべて管理する、学習・目標管理プラットフォーム**

試験日までのリアルタイムカウントダウン、学習タイムトラッキング（ストップウォッチ付き）、点数ギャップ分析、そして残り日数と点数ギャップから「今日やるべきこと」を自動で逆算する学習管理 Web アプリです。

スマホ版（ボトムナビ + 狭いフレーム表示）と PC 版（サイドバーダッシュボード）を**ワンタップで瞬時に切り替え**できます（設定は端末に保存されます）。

---

## ✨ 主な機能

| 機能 | 説明 |
|---|---|
| ⏱ カウントダウン | 日・時・分・秒のリアルタイム表示。共通テスト・国公立二次・英検・簿記・TOEIC のプリセットは公式発表済みの日程で同梱 |
| ⌚ 学習記録 & タイムトラッキング | ストップウォッチ（科目別計測）＋クイック記録モーダル。日別の棒グラフ・科目別円グラフを Recharts で可視化 |
| 📊 点数・課題分析 | 科目ごとの目標点 ⇄ 現在の実力のギャップをカード & 棒グラフで可視化。弱点単元を重点克服リスト化 |
| 🤖 自動計画 | 残り日数 × 点数ギャップ × 弱点ブーストで学習時間を配分し、今日〜3日分のタスクを逆算生成（API キー不要の決定論的ロジック） |
| 🌓 モダン UI | ダークモード対応（next-themes）、ガラス風デザイン、モバイルファースト |

> すべてのデータはブラウザの localStorage にのみ保存されます（サーバ送信なし・プライバシー安心）。

## 🛠 技術スタック

- **Next.js 14**（App Router）
- **TypeScript**（strict モード）
- **Tailwind CSS**
- **Zustand**（+ persist ミドルウェア）
- **Recharts**（グラフ）
- **next-themes**（ダークモード）
- **lucide-react**（アイコン）

## 🚀 セットアップ

```bash
git clone https://github.com/your-name/studyflow.git
cd studyflow
npm install
npm run dev
```

http://localhost:3000 を開いて利用できます。

### 本番ビルド

```bash
npm run build
npm start
```

## ☁️ Vercel へのデプロイ（約1分）

1. このリポジトリを GitHub にプッシュ
2. [vercel.com/new](https://vercel.com/new) でリポジトリを Import
3. Framework Preset は **Next.js** を自動認識（設定変更不要）
4. **Deploy** をクリック → 完了

環境変数は不要です（API キー等は一切不要の静的構成です）。

| TOEIC L&R 公開テスト | 2026/12/6(日) | IIBC |

日程は変更される場合があります。**必ず各主催団体の公式サイトで最新情報をご確認ください。**
